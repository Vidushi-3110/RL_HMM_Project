# RL + HMM Project
Q-Learning and Hidden Markov Model implementation

## 🔷 Q-Learning
- Environment: FrozenLake (OpenAI Gym)
- Algorithm: Q-Learning with epsilon-greedy
- Output:
  - Reward vs Episodes graph
  - Q-table heatmap
  - Success rate

## 🔷 Hidden Markov Model
- Library: hmmlearn
- Algorithms:
  - Baum-Welch (training)
  - Viterbi (prediction)
- Output:
  - Transition & emission matrices
  - Hidden state sequence
  - Log-likelihood

## 🔷 Results
- Q-Learning achieved ~77% success rate
- HMM learned meaningful state transitions
